订阅地址直接填入 RSS 阅读器即可。推荐刷新频率 ≥30 分钟。收到 429 按 Retry-After 退避。

公开可读，不等于可以忽略来源

  1. 重要事实回原文核对 — 摘要和翻译由人工/AI 生成。引用数字、政策或原话前，请使用返回的原文 URL 复核。
  2. 保留来源和 canonical — 对外发布请保留返回的 attribution/canonical。
  3. 按频率合同调用 — API 轮询至少间隔 60 秒，RSS 建议 30 分钟或更慢；收到 429 后按 Retry-After 退避。
  4. 稳定契约，不承诺 SLA — v1 不删除、改名或改变既有字段类型；关键链路请自行设置缓存、重试和降级。
  5. 角色切片仅改变排序与动作卡 — 不改变事实本身。
